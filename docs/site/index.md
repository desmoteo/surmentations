# surmentations: code reference

Physically grounded weather, lens and camera augmentations for
Albumentations. This site is the reference for the code, generated from it:
what each module, class and function is for and how it does it. The guides
are beside the code in the repository: `README.md` for using the library,
`docs/how_it_works.md` for the physics, `docs/transforms/` for a page per
transform with its algorithm, parameters and references, and
`docs/native_kernels.md` for the compiled kernels and the fast and exact
modes.
